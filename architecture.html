4 global filters (Time Period, Warehouse, Category, Order Status) drive all data fetches end-to-end.

Step-by-step

1
User picks a filter in FilterBar.vue
selectedLocation, selectedPeriod, selectedCategory, selectedStatus updated
2
View component watch() fires
Calls getCurrentFilters() — maps "location" → "warehouse", period → "month"
3
api.js builds URLSearchParams
axios.get('/api/orders', { params: { warehouse, category, status, month } })
4
FastAPI apply_filters() runs
Skips "all" values; case-insensitive category match; exact warehouse/status
5
filter_by_month() handles quarters
Q1-2025 → ['2025-01','2025-02','2025-03']; substring match on order_date
6
Response validated by Pydantic, returned as JSON
View stores in ref, computed properties recalculate, template re-renders

Key Patterns & Notes

Reactivity Pattern

Raw server data stored in ref() (allOrders, inventoryItems). Derived values (totals, filtered subsets) live in computed() — never mutate raw data.

Quarter Expansion

"Q1-2025"
→

→

→
substring match on order_date

Common Gotchas

  • Use unique v-for keys (sku, month) — never index
  • Validate dates before calling .getMonth()
  • Update Pydantic models when JSON structure changes
  • Inventory endpoint has no time dimension (no month filter)
  • Revenue goals: $800K/month · $9.6M YTD
  • CORS is allow_origins=["*"] — dev only
